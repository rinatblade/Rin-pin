# Rin-pin

Android-приложение для поиска товаров на Pinduoduo по-русски.

- Вводите товар по-русски → запрос переводится на китайский → поиск на Pinduoduo.
- Выдача: 5 магазинов с высоким рейтингом и большим числом продаж, сразу со ссылками (открываются в приложении Pinduoduo).
- Корзина: сохраняет товары вместе со ссылками.
- 20 тёмных и 20 светлых тем, 40 русских шрифтов.
- Иконка: флаг Китая и коробка-посылка.

## Как работает поиск

Результаты берутся из официального API Pinduoduo «多多进宝» (Duoduojinbao). Нужны ключи
`Client ID`, `Client Secret` и (для партнёрских ссылок) `PID` — вводятся в Настройки → Подключение.
Без ключей приложение переводит запрос и открывает поиск прямо в Pinduoduo.

## Сборка

APK собирается GitHub Actions (`.github/workflows/build.yml`) при каждом пуше в `main`;
готовый файл `Rin-pin.apk` появляется в Releases (`build-N`).
Шрифты скачиваются на сборке из Google Fonts (`scripts/fetch_fonts.sh`, список — `scripts/fonts.txt`).
Иконка генерируется скриптом `scripts/make_icon.py`.
